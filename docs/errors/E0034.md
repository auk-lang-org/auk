# E0034: invalid map pattern

Map patterns match fixed keys, so each key must be a literal like `{"name": n}`. A variable
key can't be used to look up an entry in a pattern.

## Wrong

```duck
fn name(m: {str: str}): str = match m {
  {k: v} => v
  _ => ""
}
```

## Fixed

```duck
fn name(m: {str: str}): str = match m {
  {"name": v} => v
  _ => ""
}
```

## Common causes

- Trying to iterate a map with a pattern: use `for k, v in m { ... }`.
- A key read from a variable: use `m.get(k)` instead.
