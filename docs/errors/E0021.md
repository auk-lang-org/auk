# E0021: expected an expression

A value was expected here (after an operator, `=`, `(` or `,`) but the next token can't start
one. Duck closures are written `x => ...`, never `fn (x) ...`.

## Wrong

```duck
fn double(xs: [int]): [int] = xs.map(fn(x) x * 2)
```

## Fixed

```duck
fn double(xs: [int]): [int] = xs.map(x => x * 2)
```

## Common causes

- A closure written with `fn`, `|x|` or `lambda`: write `x => ...` or `(a, b) => ...`.
- A dangling operator: `a + * b`, or a trailing `+` with nothing after it.
- `_` used as a value; it only works in patterns.
- `assert` used inside an expression; it is a statement.
