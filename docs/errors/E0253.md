# E0253: `?.` on a non-optional value

`x?.f` is optional chaining: it only applies when `x` is a `T?`. This value is never missing,
so use a plain `.`.

## Wrong

```duck
fn main() { print(5?.show()) }
```

## Fixed

```duck
fn main() { print(5.show()) }
```

## Common causes

- `?.` added defensively: Duck tracks optionals in types, so it's never needed on a plain value.
- A function that used to return `T?` and no longer does.
