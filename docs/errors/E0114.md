# E0114: unknown compiler intrinsic

> Internal: this error only fires for a broken declaration in the core prelude. It can't be
> triggered from user code.

An `extern` declaration in the core prelude names a compiler intrinsic (an `@` symbol) the compiler doesn't know.
This only concerns the core library's own source; user code can't declare `extern` functions
(see E0036), so seeing this error means the prelude and the compiler are out of sync.

## Wrong

Only reachable from the core prelude, e.g. in `prelude/core.auk`:

```auk
extern fn frob(n: int): int = "@frob"
```

## Fixed

```auk
fn frob(n: int): int = n
```

## Common causes

- A prelude function added without its runtime intrinsic in the compiler.
- A typo in the intrinsic's symbol name in the prelude.
- If you see this from your own program, it is a bug in Auk: please report it.
