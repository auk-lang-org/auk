# E0261: operator not defined for a user type (missing `add`/`sub`/...)

Operators call functions on user types: `+` calls `add`, `-` `sub`, `*` `mul`, `/` `div`,
`%` `mod`, and `<` calls `cmp`. This struct or enum has no such function.

## Wrong

```auk
struct V { x: int }
fn main() { print(V { x: 1 } + V { x: 2 }) }
```

## Fixed

```auk
struct V { x: int }
fn add(a: V, b: V): V = V { x: a.x + b.x }
fn main() { print(V { x: 1 } + V { x: 2 }) }
```

## Common causes

- Using `+`, `<` etc. on your own type without defining `add`, `cmp`, ...
- `==` is automatic for structs, enums and tuples; ordering is not (define `cmp`).
