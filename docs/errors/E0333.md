# E0333: un-awaited `async fn` call used as its result

An `async fn` call is a task, not its result. Using it where the result is expected (in
arithmetic, as an argument, as a return value) needs an `await` first.

## Wrong

```duck
async fn get(): int = 1
fn main() { print(get() + 1) }
```

## Fixed

```duck
async fn get(): int = 1
fn main() { print(await get() + 1) }
```

## Common causes

- A forgotten `await`.
- A function that became `async` after its callers were written.
