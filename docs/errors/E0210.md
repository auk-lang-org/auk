# E0210: integer literal out of range

The literal doesn't fit in an `int` (64-bit, from -9223372036854775808 to
9223372036854775807). Duck never wraps a literal silently.

## Wrong

```duck
let LIMIT = 9223372036854775808
```

## Fixed

```duck
let LIMIT = 9223372036854775807
```

## Common causes

- An off-by-one on the maximum `int`.
- A value that needs a `float`: write `9.3e18`.
- A big ID that should be a `str`.
