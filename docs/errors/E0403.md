# E0403: pattern that might not match where one must always match

A plain `let`, a `for` loop and function parameters bind with patterns that must match every
value. This one might not; the message shows a value it misses. Auk never fails a binding
silently at run time.

## Wrong

```auk
fn head(xs: [int]): int {
  let [h, ..t] = xs
  h
}
```

## Fixed

```auk
fn head(xs: [int]): int {
  let [h, ..t] = xs else { return 0 }
  h
}
```

## Common causes

- Destructuring a list, enum or literal with a plain `let`: add `else { ... }`, or use `match`.
- `for Circle(r) in shapes`: filter first, or `match` inside the loop.
