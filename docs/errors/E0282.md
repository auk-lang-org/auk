# E0282: malformed format spec

The part after `:` in an interpolation isn't a valid format spec. Specs are an optional
alignment `<`, `>` or `^` with a width, an optional `0` for zero-padding, and an optional
precision: `{x:.2}`, `{n:>5}`, `{n:05}`, `{s:<10}`.

## Wrong

```duck
fn hex(n: int): str = "{n:x}"
```

## Fixed

```duck
fn hex(n: int): str = "{n:>8}"
```

## Common causes

- Format types from Python or Rust (`:x`, `:b`, `:e`, `:?`): not supported.
- A `:` in the text right after an interpolation: write `{x}{{` ... or separate it with a
  space.
