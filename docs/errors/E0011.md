# E0011: semicolons are not used

Auk has no semicolons: a line break ends a statement. Having exactly one way to separate
statements keeps code uniform, so a `;` is reported (with a fix that deletes it).

## Wrong

```auk
fn main() {
  let x = 1;
  print(x)
}
```

## Fixed

```auk
fn main() {
  let x = 1
  print(x)
}
```

## Common causes

- Habit from C, Rust, Java or JavaScript.
- Two statements on one line (`a = 1; b = 2`): put each on its own line.
