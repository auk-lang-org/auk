# E0331: `await` on something that is not a task

`await` waits for an `async fn` call, a task, or a tuple or list of them. This value is a plain
value that is already available, so there is nothing to wait for.

## Wrong

```duck
fn get(): int = 1
fn main() { print(await get()) }
```

## Fixed

```duck
fn get(): int = 1
fn main() { print(get()) }
```

## Common causes

- `await` on a normal (non-`async`) function: remove it, or make the function `async fn`.
- Awaiting a value twice.
