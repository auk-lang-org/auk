# E0025: expected the end of the statement

Each statement or item goes on its own line, so something after a complete statement on the
same line is an error. (A line that ends with an operator, `=`, `,` or an open bracket
continues on the next line.)

## Wrong

```auk
fn main() {
  let a = 1 let b = 2
  print(a + b)
}
```

## Fixed

```auk
fn main() {
  let a = 1
  let b = 2
  print(a + b)
}
```

## Common causes

- Two statements on one line: split them.
- A missing operator between two values: `a b` instead of `a + b`.
- Two items on one line: `fn a() = 1 fn b() = 2`.
