# E0020: unexpected token

The parser expected one specific token (the message says which) and found something else.
This is the general syntax error; the note usually shows the expected form.

## Wrong

```duck
fn add(a: int b: int): int = a + b
```

## Fixed

```duck
fn add(a: int, b: int): int = a + b
```

## Common causes

- A missing `,` between parameters, arguments, fields or list items.
- `=` instead of `==` in an `if` or `while` condition.
- Two match arms on one line without a `,` between them.
- `..base` not last in a struct literal.
