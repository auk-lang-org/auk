# E0007: malformed char literal

A char literal (single quotes) must hold exactly one character, like `'a'` or `'\n'`. It is
empty, unterminated, or holds several characters. Strings use double quotes.

## Wrong

```auk
fn greeting(): str = 'hello'
```

## Fixed

```auk
fn greeting(): str = "hello"
```

## Common causes

- Single quotes used for a string, as in Python or JavaScript.
- An empty `''`.
- A forgotten closing `'`.
