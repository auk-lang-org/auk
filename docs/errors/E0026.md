# E0026: comparison operators cannot be chained

`a < b < c` would compare a `bool` with `c` in most languages, and mean a range test in others.
Duck rejects it rather than pick one reading; spell out what you mean.

## Wrong

```duck
fn between(a: int, b: int, c: int): bool = a < b < c
```

## Fixed

```duck
fn between(a: int, b: int, c: int): bool = a < b && b < c
```

## Common causes

- A math-style range check: write `lo <= x && x < hi`.
- Comparing three values for equality: `a == b && b == c`.
