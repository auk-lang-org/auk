# E0101: module name collides with a dependency

A file `src/json.auk` makes a module `json`, and the package also depends on a package named
`json`. Since `json.` would then be ambiguous, Auk rejects the clash instead of picking one.

## Wrong

The project depends on `json` (installed by `raft install`) and also has `src/json.auk`:

```toml raft.toml
[package]
name = "app"
version = "0.1.0"

[deps]
json = "^0.1"
```

```auk src/json.auk
pub fn pretty(s: str): str = s
```

```auk .raft/json/src/lib.auk
pub fn parse(s: str): int = s.len()
```

```auk
fn main() { print(json.pretty("[1]")) }
```

## Fixed

Drop the dependency you don't use from `raft.toml` (or rename `src/json.auk`):

```toml raft.toml
[package]
name = "app"
version = "0.1.0"
```

## Common causes

- A helper module named after a library you also depend on, or a dependency added later.
