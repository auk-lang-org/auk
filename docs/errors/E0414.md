# E0414: unknown effect

`uses` takes only the built-in effects: `fs`, `net`, `time`, `rand`, `env`, `proc` and `ffi`.
This name isn't one of them; the message may suggest the one you meant.

## Wrong

```duck
fn greet() uses io { print("hi") }
```

## Fixed

```duck
fn greet() { print("hi") }
```

## Common causes

- A typo or long form (`fss`, `random`, `times`).
- An effect name from another system (`io`, `file`, `http`): files are `fs`, sockets `net`.
- `print` needs no effect at all.
