# E0005: integer literal too large

The integer literal doesn't fit in 64 bits. `int` is a 64-bit signed integer, so the largest
literal is `9_223_372_036_854_775_807`; Auk never silently wraps or truncates a literal.

## Wrong

```auk
let BIG = 99999999999999999999
```

## Fixed

```auk
let BIG = 9_223_372_036_854_775_807
```

## Common causes

- A constant that really needs a `float`: write `1e20`.
- Too many digits typed by accident.
- A big number meant as text (an ID or card number): keep it in a `str`.
