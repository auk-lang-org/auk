# E0103: no function for this receiver type (dot call)

`x.f(a)` means `f(x, a)`: Duck looks for a function `f` whose first parameter fits the type of
`x`, in `x`'s module, the current one and core. None was found for this type.

## Wrong

```duck
fn main() {
  print(5.trim())
}
```

## Fixed

```duck
fn main() {
  print(str(5).trim())
}
```

## Common causes

- Calling a method meant for another type (`trim` is for `str`, not `int`).
- A missing conversion: `str(n)`, `float(n)`, `int(x)`.
- A misspelled method name, or one that doesn't exist in core.
- The function exists but takes a different number of arguments.
