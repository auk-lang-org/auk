# E0120: private item

Items are private to their module unless marked `pub`. Another module of the program referred
to a function, constant or type that isn't public. Privacy keeps a module's helpers free to
change without breaking callers.

## Wrong

```toml quack.toml
[package]
name = "app"
version = "0.1.0"
```

```duck src/geo.duck
fn secret(): int = 2
```

```duck
fn main() { print(geo.secret()) }
```

## Fixed

```duck src/geo.duck
pub fn secret(): int = 2
```

## Common causes

- Forgetting `pub` on a function meant to be used elsewhere.
- Calling another module's internal helper: use its public API instead.
- A `pub fn` whose signature mentions a private type.
