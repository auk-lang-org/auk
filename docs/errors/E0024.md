# E0024: expected an item

At the top level of a file only items are allowed: `fn`, `struct`, `enum`, `shape`, `test`,
`let` and `imprint`. Statements belong inside a function, and Duck has no `import`: anything is
reached by its path.

## Wrong

```duck
print("hello")
```

## Fixed

```duck
fn main() {
  print("hello")
}
```

## Common causes

- Script-style code at the top level: put it in `fn main()`.
- `import json` or `use std::fs`: delete it and write `json.parse(s)` directly.
- A stray token after an item, such as an extra `}`.
