# E0001: unexpected character

The lexer found a character that can't start any Duck token, such as `$`, `@` or `#`.
Duck has one spelling for each operator, so look-alikes from other languages are rejected
instead of guessed at.

## Wrong

```duck
fn price(n: int): str = $"{n} USD"
```

## Fixed

```duck
fn price(n: int): str = "{n} USD"
```

## Common causes

- `$"..."` from C#: every Duck string interpolates `{x}` already.
- `#` for a comment: Duck uses `//` and `/* */`.
- A stray character pasted from another language (`$x`, `@decorator`, a backtick).
- A smart quote (`“` or `’`) copied from a document instead of `"` or `'`.
