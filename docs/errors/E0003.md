# E0003: unterminated block comment

A `/*` comment was never closed with `*/`. Block comments nest in Duck, so every `/*` inside
the comment needs its own `*/` as well.

## Wrong

```duck
/* compute the area
fn area(r: float): float = 3.14 * r * r
```

## Fixed

```duck
/* compute the area */
fn area(r: float): float = 3.14 * r * r
```

## Common causes

- A missing `*/`.
- Commenting out code that already contains a `/*`: the inner comment needs its own `*/`.
- Use `//` line comments for short notes; they can't be left open.
