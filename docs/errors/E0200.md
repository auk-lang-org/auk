# E0200: mismatched types

A value of one type was used where another type is expected. Duck has no implicit conversions
(not even `int` to `float`), so every conversion is visible in the code: `float(n)`, `int(x)`,
`str(v)`.

## Wrong

```duck
fn label(n: int): str = n
```

## Fixed

```duck
fn label(n: int): str = str(n)
```

## Common causes

- A missing conversion between `int`, `float` and `str`.
- A function without a return type (`: T`) whose body produces a value: it returns `()`.
- `if` and `else` branches that produce different types.
- `return` without a value in a function that returns something.
