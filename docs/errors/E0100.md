# E0100: dependency or file not found

A dependency listed in `raft.toml` isn't installed under `.raft/`, or a source file of the
program couldn't be read. Auk resolves every path (`geo.area`) at compile time, so a missing
package is reported up front instead of failing later.

## Wrong

```toml raft.toml
[package]
name = "app"
version = "0.1.0"

[deps]
geo = "^0.1"
```

```auk
fn main() { print(geo.double(2)) }
```

## Fixed

Run `raft install`, which fetches `geo` into `.raft/geo/`:

```auk .raft/geo/src/lib.auk
pub fn double(n: int): int = n * 2
```

## Common causes

- `raft install` hasn't been run since the dependency was added (or after a fresh clone).
- The `.raft/` folder was deleted or is out of date.
- A typo in the dependency name in `raft.toml`.
