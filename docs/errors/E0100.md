# E0100: dependency or file not found

A dependency listed in `quack.toml` isn't installed under `.quack/`, or a source file of the
program couldn't be read. Duck resolves every path (`geo.area`) at compile time, so a missing
package is reported up front instead of failing later.

## Wrong

```toml quack.toml
[package]
name = "app"
version = "0.1.0"

[deps]
geo = "^0.1"
```

```duck
fn main() { print(geo.double(2)) }
```

## Fixed

Run `quack install`, which fetches `geo` into `.quack/geo/`:

```duck .quack/geo/src/lib.duck
pub fn double(n: int): int = n * 2
```

## Common causes

- `quack install` hasn't been run since the dependency was added (or after a fresh clone).
- The `.quack/` folder was deleted or is out of date.
- A typo in the dependency name in `quack.toml`.
