# E0004: malformed number literal

A number literal contains a character that doesn't belong in it, or a radix prefix such as `0x`
has no digits after it. Literals look like `1_000`, `0xff`, `0b1010`, `3.14` or `1e-9`.

## Wrong

```duck
let MASK = 0xfg
```

## Fixed

```duck
let MASK = 0xff
```

## Common causes

- A digit that is invalid for the radix (`0b102`, `0xfg`).
- A unit or type suffix from another language (`10px`, `5u8`, `1.0f`).
- A prefix with nothing after it (`0x`).
