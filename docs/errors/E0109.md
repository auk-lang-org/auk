# E0109: parameter type can't be determined

Every parameter needs a type: annotate it in one clause (`x: T`) or in a header line. A literal
pattern like `0` or `"a"` implies its type, but a bare name or `_` alone doesn't. Duck doesn't
infer parameter types from the body, so signatures stay readable on their own.

## Wrong

```duck
fn double(x) = x * 2
```

## Fixed

```duck
fn double(x: int): int = x * 2
```

## Common causes

- A parameter written without `: Type`, as in Python or JavaScript.
- All clauses use patterns that don't fix the type (`_`, `[]` for a list of what?).
- A shape method parameter other than `self` with no type.
