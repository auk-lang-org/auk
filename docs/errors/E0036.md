# E0036: `extern` outside the core prelude

`extern` declarations bind runtime functions and are reserved for Auk's core prelude. User
code reaches the outside world through the core library and declared effects (`uses fs, net,
...`), so there is no FFI syntax.

## Wrong

```auk
extern fn getpid(): int = "getpid"
```

## Fixed

```auk
fn pid(): int = 0
```

## Common causes

- Trying to call a C function directly: use the core library (`proc.run`, `env.get`, ...).
- Code copied from the prelude sources into a program.
