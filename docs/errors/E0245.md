# E0245: bad `break` value

Only `loop` is an expression that can produce a value with `break v`; `for` and `while` may
stop before running at all, so they have no value to break with.

## Wrong

```duck
fn main() {
  while true { break 1 }
}
```

## Fixed

```duck
fn main() {
  let v = loop { break 1 }
  print(v)
}
```

## Common causes

- `break value` in a `for` or `while`: use `loop`, or `find`/`find_index` to search.
- A `break value` whose type doesn't match the other `break`s of the same `loop`.
