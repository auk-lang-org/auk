# E0104: unknown type

The type name isn't a built-in type (`int`, `float`, `bool`, `char`, `str`, ...) and no
`struct`, `enum` or `shape` with that name is in scope.

## Wrong

```auk
fn shout(s: string): str = s.upper()
```

## Fixed

```auk
fn shout(s: str): str = s.upper()
```

## Common causes

- A type name from another language: `string`, `i32`, `Vec`, `bool8`.
- A typo, or a type defined in another module without its path (`geo.Circle`).
- `Self` used outside a shape.
