# E0241: bad `fail` argument

`fail(e)` returns an error from the function. In a `T!` function `e` is a `str` message or an
`Err`; in a `T!E` function it must be a value of the error enum `E`.

## Wrong

```duck
fn check(n: int): int! {
  if n < 0 { fail(n) }
  n
}
```

## Fixed

```duck
fn check(n: int): int! {
  if n < 0 { fail("negative: {n}") }
  n
}
```

## Common causes

- Failing with a number or other plain value: wrap it in a message.
- A message in a `T!E` function: fail with a variant of `E` instead, e.g. `fail(Bad(n))`.
