# E0010: triple-quoted string line indented less than its closing quotes

A `"""` string strips the closing line's indentation from every line, so every line must be
indented at least that much. A line that is indented less would lose real text.

## Wrong

```auk
fn poem(): str {
  let s = """
    roses
  red
    """
  s
}
```

## Fixed

```auk
fn poem(): str {
  let s = """
    roses
    red
    """
  s
}
```

## Common causes

- A line pasted without indentation.
- The closing `"""` indented further than the text: move it left.
- Tabs and spaces mixed between lines.
