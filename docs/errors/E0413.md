# E0413: effect not allowed by the package's quack.toml

A package's `quack.toml` lists in `[package] effects` the most its code may use. A function
uses an effect outside that ceiling. This lets you see, and limit, what a package can do
before depending on it.

## Wrong

```toml quack.toml
[package]
name = "app"
version = "0.1.0"
effects = []
```

```duck
fn main() uses time { time.sleep(1) }
```

## Fixed

```toml quack.toml
[package]
name = "app"
version = "0.1.0"
effects = ["time"]
```

## Common causes

- A new effect used in a package: add it to `effects` (a visible, reviewable change).
- A dependency that started using an effect your manifest doesn't allow it.
