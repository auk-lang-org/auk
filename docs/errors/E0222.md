# E0222: field access on an optional (use `?.`)

The value is a `T?` and may be missing, so it has no fields of its own. Duck makes the missing
case explicit: chain with `?.` and give a fallback, or unwrap first.

## Wrong

```duck
struct P { x: int }
fn get(p: P?): int = p.x
```

## Fixed

```duck
struct P { x: int }
fn get(p: P?): int = p?.x else 0
```

## Common causes

- A lookup (`find`, `get`, `first`) returns `T?`: use `?.`, `?`, `else` or `match`.
- `x?.f` works on `T?` only; for `T!` write `(x?).f`.
