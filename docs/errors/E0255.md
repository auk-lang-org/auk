# E0255: `else` on a value that can't fail

`else` handles the bad case of a `T!`, a `T?`, or a pattern that might not match. This value is
a plain type and the pattern always matches, so the `else` could never run.

## Wrong

```duck
fn main() {
  let x = 1 else 2
  print(x)
}
```

## Fixed

```duck
fn main() {
  let x = 1
  print(x)
}
```

## Common causes

- A function that used to return `T?` or `T!` and now returns a plain value.
- `else` used as a general "or" operator: use `if`/`else` for conditions.
